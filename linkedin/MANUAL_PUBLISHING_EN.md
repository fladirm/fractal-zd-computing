# LinkedIn: manual publication, step by step

**English** · [Čeština](MANUAL_PUBLISHING_CS.md)

## Prepared files

Open the repository's `linkedin` folder:

- `POST_EN_READY.txt`: complete English post text, ready to copy.
- `LINKEDIN_CAROUSEL_EN.pdf`: the single English attachment, six pages.
- `POST_CS_READY.txt` and `LINKEDIN_CAROUSEL_CS.pdf`: the Czech follow-up for later publication.

The four paper PDFs are already available through the repository and release links. Attach only the English carousel document to this post.

## English post

1. Open your LinkedIn home feed and confirm the author is **Vladimír Bíža**, using the exact profile URL in `PROFILE_TARGET.md`.
2. Click **Start a post**.
3. Check the audience beside the author's name. Select **Anyone** for a public post.
4. At the bottom of the editor, click **… / More**, then **Add a document**.
5. Click **Choose file** and select `LINKEDIN_CAROUSEL_EN.pdf` from the `linkedin` folder. In a Linux file picker, **Ctrl+L** lets you paste its full path and press Enter.
6. Enter this exact document title: **533 Million Zero-Product Relations — Fractal ZD Computing**.
7. Wait for the six-page preview to finish loading, then click **Done**.
8. Open `POST_EN_READY.txt` in a text editor. Use **Ctrl+A**, **Ctrl+C**, then **Ctrl+V** in the post text field. The file has no Markdown markers or working heading.
9. Check the author, public audience, English document, six pages, repository URL and live-demo URL.
10. Click **Post** and wait for the published post to appear.
11. Open **… → Copy link to post** on the published item. Record that actual permalink in `PUBLICATION_RESULTS.md`, or send it back to Codex for verification and recording.

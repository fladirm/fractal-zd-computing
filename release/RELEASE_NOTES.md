# Fractal Zero-Divisor Computing v1.0.0

**English** · [Čeština](RELEASE_NOTES_CS.md)

Independent mathematics and computer science by **Vladimír Bíža**.

This release contains Paper A (signed Cayley–Dickson information forest and higher-π invariants) and Paper B (generative operators and computing), each in English and Czech. The four original paper PDFs are attached; Markdown, HTML and TeX sources are in the repository.

- Project website: https://fladirm.github.io/fractal-zd-computing/
- Interactive demo: https://fladirm.github.io/fractal-zd-computing/demo/
- Verification notes: https://github.com/fladirm/fractal-zd-computing/blob/main/release/PREFLIGHT.md

The reference code implements signed basis multiplication, qualified two-term assessor incidence, inherited factorized operators and higher-order probes. The designated unsigned two-term assessor census at K2048 is **533,208,060** edges. This count does not enumerate all continuous zero divisors. Fourfold inheritance and a separate newborn-edge budget are preserved; one Kronecker inflation is only an inherited component.

The offline HTML demo runs directly from a file, with no CDN, server or API key. Its four scenes demonstrate address queries, recovery conditional on surviving redundant observations, the exact witness `XY=0` with `[X,e1,Y]=−4e7`, and edge birth across doublings.

Validation: Python oracle and educational benchmark pass; five Rust tests pass; all nine internal browser checks and 24 offline interaction checks pass. Explicit and factorized implementations agree. These checks do not establish general speed superiority over CSR/GraphBLAS or optimized matrix-free operators. Zero product is not encryption, tenant isolation or consensus, and recovery requires sufficient surviving information.

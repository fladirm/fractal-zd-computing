\section{Fractal Zero-Divisor Computing --- B: Generative Operators and
Parallel
Computing}\label{fractal-zero-divisor-computing-b-generative-operators-and-parallel-computing}

\textbf{Author:} Vladimír Bíža\\
\textbf{Research manuscript · English technical edition · 25 October
2026}\\
\textbf{Scope:} Mathematics and computer science; independent of any
physical theory.

\subsection{Abstract}\label{abstract}

We translate a signed Cayley--Dickson information forest into a
practical algorithmic design: compute algebraically determined
relationships at query time, represent inherited adjacency as a
matrix-free operator, track new qualified relations in a separate
frontier, and preserve noncommutative, nonassociative and nonalternative
information as typed channels. We provide a resource model, PostgreSQL
storage design, GPU execution plan and reproducible Python/Rust
reference workflow. The design is intended for compatible computational
structures, not as a universal replacement for sparse algebra, databases
or consensus.

\subsection{1. The computational primitive is a structural
address}\label{the-computational-primitive-is-a-structural-address}

Use a typed structural key rather than allocating an object for every
implied graph edge. An address includes its Cayley--Dickson level, basis
indices, XOR color, orientation, relative sign, ancestry word, birth
level, and relation type. A sign oracle evaluates a basis product using
O(log N) stages and constant auxiliary storage in an iterative
implementation.

The XOR color never replaces all four indices of a plaquette. A relation
type distinguishes ZD, NZD, commutator, associator, alternator, shared
incidence and birth. A mathematical key specifies algebraic structure
but does not itself store arbitrary application data.

\subsection{2. Do not store annihilating matrices; apply their
operators}\label{do-not-store-annihilating-matrices-apply-their-operators}

For an inherited component, the adjacency is A₀⊗J\_m. Matrix--vector
multiplication can be performed by reducing each ancestry block to a
scalar, multiplying the root vector by the small sparse root adjacency,
and broadcasting each root response to descendants. This has work
Θ(rm+e) for r root vertices and e root edges instead of Θ(r²m²) dense
work, excluding input/output storage.

The Python reference below shows the exact transformation. Crucially, it
models the inherited component only; the complete zero-divisor forest
also has newly born components. The speedup here is a property of matrix
factorization, shared with general implicit linear operators, not an
automatic breakthrough of zero-divisor algebra over all structured
solvers.

\[
s_q=\sum_{v=1}^{m} x_{q,v},\quad r_p=\sum_q (A_0)_{pq}s_q,\quad y_{p,u}=r_p.
\tag{1}
\]

\subsection{3. Inherited structure versus born
frontier}\label{inherited-structure-versus-born-frontier}

At each doubling we distinguish (a) an immutable root or known inherited
factor, (b) the signed recursion, (c) a frontier describing newly
qualified edges, and (d) optional caches. The number of newborn edges is
exactly E\_\{2N\}−4E\_N, but a count is not a constructive enumerator.
To materialize the frontier one must actually generate candidate address
tuples or use an equivalent constructive classifier and confirm them
with the plaquette predicate.

A useful API reports not just a boolean zero-product decision but
provenance: which root generated the relation, its sign, its generation
and the check that certified it.

\subsection{4. Applications to AI and stateful
systems}\label{applications-to-ai-and-stateful-systems}

The algebraic forest is a structural index, not a pretrained cognitive
model. In AI and graph-like application state we distinguish an
algebraic key, recorded mutable state, and semantic payload. Only
mathematically implied incidences are recomputed; actual learned
parameters, observations and commitments must be persisted.

Triples preserve explicit parentheses. An associative reduction or a
careless GPU kernel can destroy the information carried by
nonassociativity. Krylov observability permits an exact test for which
operator dimensions are absent from a selected readout. These are
potential components of AI infrastructure and query planning, not
evidence that the algebra alone learns tasks.

\subsection{5. Memory hierarchy: VRAM, RAM and
NVMe}\label{memory-hierarchy-vram-ram-and-nvme}

Keep active sparse amplitudes, GPU batches and Krylov workspaces in
VRAM; ancestry indexes, caches and the current birth frontier in RAM;
and immutable roots, committed application deltas and provenance on
NVMe. Avoid storing a full Cayley--Dickson multiplication table if only
a small signed support is active. The memory required for actual dense
state vectors still scales with the amount of state; an address oracle
does not compress arbitrary user data.

\subsection{6. GPU parallelism and deterministic
execution}\label{gpu-parallelism-and-deterministic-execution}

Partition kernels by XOR color, ancestry prefix, relation kind and
active support. For inherited blocks perform reduction and root
aggregation, then broadcast. For born blocks use filtered enumeration
and sparse gathers. Signed basis multiplication groups naturally by XOR
and the recursive sign bit; struct-of-arrays layouts permit coalesced
loads. Synchronization remains necessary wherever associators or other
probes couple otherwise independent blocks.

A safe deterministic pipeline preserves orientation, relative sign,
provenance, and complete parenthesization. The steps below are an
implementation contract rather than an empirical performance claim.

\subsection{7. Databases and generic
trees}\label{databases-and-generic-trees}

Two separate concepts should not be conflated: a source-algebra index
with fully determined signed identities, and a generic hierarchical
business-data index inspired by algebraic structural sharing. An
arbitrary customer relationship cannot be reconstructed from XOR bits
unless explicitly mapped and qualified.

The PostgreSQL example separates immutable algebraic roots from
persistent delta records. Real semantic payloads are content addressed
and stored transactionally. Binary canonical address keys should use
byte encoding when fixed-width integer types are insufficient.

\subsection{8. Higher-π invariants as exact test
oracles}\label{higher-ux3c0-invariants-as-exact-test-oracles}

The mathematics companion supplies exact quantities such as V\_N, Φ\_N,
Q\_N, phase-restricted Q\_N and the norm-weighted compound C\_N. Q\_N is
a mean squared norm-multiplicativity defect of independent unit source
vectors and serves as a deterministic analytical target for validating a
signed kernel. It is not a free performance multiplier or a proxy for
intelligence.

The Fraction-based Python reference avoids Monte Carlo as a correctness
oracle. A runtime may optionally collect sampled numerical estimates,
but must compare those against the exact rational formula under
well-defined tolerances.

\subsection{9. Reproducibility and benchmarking
contract}\label{reproducibility-and-benchmarking-contract}

The supplied Python scripts check the canonical zero-divisor counts and
moment identities. A Rust reference implements the signed oracle and
should be compiled and tested on the target machine before claims about
native speed are made. Compare implementations on matching workloads and
record RSS, GPU memory, p50/p99 latency, throughput, and correctness.

Fair baselines include explicit sparse representations such as
CSR/GraphBLAS and optimized matrix-free/Kronecker operators. The latter
can match the factorized application cost; the distinct contribution of
the zero-divisor atlas is the signed generative incidence,
multi-operator typing and newborn-edge genealogy.

\subsection{10. First computing
synthesis}\label{first-computing-synthesis}

The key engineering principle is to store qualified novelty and
application payload while deriving every mathematical relation that the
algebra can reconstruct. This is useful when the application has a
compatible structure, not as a universal replacement for databases,
consensus or access control. A zero product is not a confidentiality
primitive, and rank-based recovery requires adequate independent
surviving information.

\subsection{11. Complete typed contract and
invariants}\label{complete-typed-contract-and-invariants}

Separate AlgebraKey, StorageKey and SemanticPayload. The algebraic key
records convention and tower version, full signed address, root and
operator type. The storage key additionally records epoch and
persistence identity; payload is an independent content-addressed datum.
Nothing in the signed recursion recreates an unrecorded user event.

A compiler must distinguish Mul(Mul(x,y),z) from Mul(x,Mul(y,z)).
Cross-device tests validate exact signs, supports and associators
separately from floating-point tolerances.

\subsection{12. Compute kernels and cost
model}\label{compute-kernels-and-cost-model}

Let the root have r nodes and e edges, with m=2\^{}t descendants per
root. An explicit dense adjacency stores r²m² entries. The factorized
inherited matvec uses Θ(rm+e) operations and O(r) scratch beyond
input/output, with no need for r²m² temporary storage. A random edge
query needs the root addresses, signed predicate and ancestry; no full
matrix allocation.

Newborn-edge enumeration is separate. It performs deterministic
candidate generation, W=+1 classification and deduplication of signed
keys. Replacing the old matrix with only a Kronecker factor computes
only an inherited subgraph, not the entire source forest.

\subsection{13. Parallel determinism and
persistence}\label{parallel-determinism-and-persistence}

Partition work units by level, XOR color, root, ancestry prefix and
channel and assign a monotonic epoch. Each unit produces an immutable
delta with its source hash, operator and payload hash. Floating-point
reductions need a prescribed merge order; symbolic operations may be
reordered only when the particular algebraic operation permits it.
Persist application events transactionally and reconstruct inherited
mathematics on demand.

A cold restart validates tower-sign convention, root fingerprints and
persisted provenance. Multi-channel probes preserve zero/nonzero,
commutator, associator, alternator and birth responses as separate
outputs; incomplete Krylov rank is reported as an unobservable
complement.

\subsection{14. Regression and experimental
protocol}\label{regression-and-experimental-protocol}

The explicit and factorized matvec references must produce identical
outputs on identical inputs at small dimensions before benchmark curves
are reported. Record algorithm name, dimension, elapsed time, memory
estimate and correctness status. Do not extrapolate one device's
measured latency into a universal hardware theorem.

Any learning-oriented application needs independent tests for structural
correctness, persistence correctness and actual competence changes,
preferably with the teaching oracle removed during evaluation. Memory
compression is not by itself evidence of learning.

\subsection{15. Conclusion}\label{conclusion}

The signed Cayley--Dickson convention gives an addressable algebraic
oracle; the inherited genealogy gives fast implicit operators; the birth
frontier preserves genuine new edges; and higher-order probes retain
information absent from a pairwise adjacency. The construction provides
a concrete, testable software architecture for compatible mathematical
state spaces. Its algorithms and their limitations are explicit,
enabling fair reproducible comparison against contemporary sparse and
structured operators.
